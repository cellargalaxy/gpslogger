# 260616-014719 执行记录

## 依据来源

- 任务来源：`vibe/2606p1/260616-014719-prompt.md`，要求地图图层类型支持可选：`OpenStreetMap`、`CyclOSM`、`esriWorldImagery`，且类似图层需要支持本地缓存。
- 当前地图 SDK：`gpslogger/build.gradle` 中依赖 `org.maplibre.gl:android-sdk:11.5.2`。
- 当前内置底图：`gpslogger/src/main/assets/styles/openstreetmap.json` 已是 MapLibre raster style，瓦片 URL 为 `https://tile.openstreetmap.org/{z}/{x}/{y}.png`。
- 当前显示链路：`TrackMapViewFragment.loadConfiguredStyle()` 读取 `TrackerPreferenceHelper.getOfflineMapStyleUrl()` 后调用 MapLibre `setStyle(...)`。
- 当前缓存链路：`TrackMapViewFragment.cacheVisibleRegionIfEnabled()` 打开「缓存视野」后调用 `MapLibreOfflineMapStore.enableAmbientCacheRetention()`，公共 OSM 分支只依赖 MapLibre ambient cache；非公共样式才创建 `OfflineRegion`。
- OSM 官方 Tile Usage Policy 确认：标准瓦片 URL 是 `https://tile.openstreetmap.org/{z}/{x}/{y}.png`；要求配置明确 User-Agent、按缓存头本地缓存；禁止 bulk download / offline use。来源：https://operations.osmfoundation.org/policies/tiles/
- CyclOSM 官方页确认：TMS 模板为 `https://{s}.tile-cyclosm.openstreetmap.fr/[cyclosm|cyclosm-lite]/{z}/{x}/{y}.png`；默认 CyclOSM 样式瓦片可缓存数小时，高缩放 live-generated 后最多缓存 72 小时；遵循 fair-use tile policy。来源：https://www.cyclosm.org/
- Esri World Imagery ArcGIS REST 元数据确认：服务 `World_Imagery/MapServer` 为 `singleFusedMapCache=true`，`tileInfo.rows/cols=256`，格式 `JPEG`，LOD `0-23`，`copyrightText=Source: Esri, Vantor, Earthstar Geographics, and the GIS User Community`，且 `exportTilesAllowed=false`。来源：https://services.arcgisonline.com/ArcGIS/rest/services/World_Imagery/MapServer?f=pjson

## 需求拆解与方案

1. 图层可选：沿用既有偏好 key `offline_map_style_url`，把设置页中的自由文本 `EditTextPreference` 改为三选一 `ListPreference`。这样现有读取链路不变，默认仍是 `builtin:openstreetmap`。
2. 内置样式解析：新增 `builtin:cyclosm` 与 `builtin:esriWorldImagery`，统一由 `OpenStreetMapStyle.resolveStyleUri(...)` 映射到 APK assets 中的 MapLibre style JSON。
3. 本地缓存边界：对 OpenStreetMap、CyclOSM、Esri World Imagery 三种内置公共/托管图层，只支持 MapLibre ambient cache，即“用户实际浏览过的瓦片本地缓存”。不对它们创建 `OfflineRegion` 预下载区域，因为 OSM/CyclOSM 明确限制预取/离线用途，Esri 元数据 `exportTilesAllowed=false`。
4. 兼容性：保留旧自定义样式 URL 的读取能力；如果已有用户偏好中存的是非 `builtin:` URL，helper 仍返回原 URL。只有未知 `builtin:*` 会回退默认 OpenStreetMap。

## 实施内容

- `gpslogger/src/main/res/xml/pref_tracker.xml`
  - `offline_map_style_url` 从 `EditTextPreference` 改为 `ListPreference`。
  - 候选项为 `OpenStreetMap`、`CyclOSM`、`Esri World Imagery`。
- `gpslogger/src/main/res/values/strings.xml`、`gpslogger/src/main/res/values-zh-rCN/strings.xml`
  - 新增 `tracker_offline_map_layer_entries` / `tracker_offline_map_layer_values`。
  - 将相关文案从“地图样式 URL / OpenStreetMap”泛化为“地图图层 / 公共或托管图层”。
- `gpslogger/src/main/assets/styles/cyclosm.json`
  - 新增 CyclOSM raster style，瓦片 URL 使用已验证的 `https://a.tile-cyclosm.openstreetmap.fr/cyclosm/{z}/{x}/{y}.png`。
- `gpslogger/src/main/assets/styles/esri_world_imagery.json`
  - 新增 Esri World Imagery raster style，瓦片 URL 为 ArcGIS REST cache tile 路径 `.../MapServer/tile/{z}/{y}/{x}`。
- `OpenStreetMapStyle.java`
  - 新增三种内置图层 URI、tile URL、style JSON 生成方法。
  - 新增 `resolveStyleUri(...)` 和 `usesPublicOrManagedTiles(...)`，集中处理内置图层解析与禁止离线区域预下载判断。
- `TrackerPreferenceNames.java`、`TrackerPreferenceHelper.java`
  - 新增 `builtin:cyclosm`、`builtin:esriWorldImagery` 常量。
  - 新增 `isOfflineMapUsingPublicTileLayer()`，旧 `isOfflineMapUsingPublicOpenStreetMapTiles()` 保留为兼容委托。
- `TrackMapViewFragment.java`
  - 地图加载改为 `OpenStreetMapStyle.resolveStyleUri(...)`。
  - 「缓存视野」对三种内置公共/托管图层都走 ambient cache 提示分支。
- `MapLibreOfflineMapStore.java`
  - `createRegion(...)` 对公共/托管图层统一拒绝创建 offline region。
  - 自定义样式仍可创建 region，前提是服务商允许。
- `OfflineMapManagerActivity.java`
  - 预览图也使用当前解析后的图层 style；虽然当前无入口注册，但保持编译路径一致。

- 已确认：三种内置公共/托管图层打开「缓存视野」后都使用本地 ambient cache，受既有最大地图缓存大小限制。
- 已确认：三种内置公共/托管图层不会触发 MapLibre `OfflineRegion` 批量预下载。
- 待确认：缺少 JDK，无法在本环境完成 Android 编译与真机渲染验证。
- 待确认：MapLibre 在真机上对第三方服务缓存头的具体 TTL 执行效果需设备侧验证。
