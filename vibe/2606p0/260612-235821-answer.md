## 需求拆解与取舍

1. 当前位置醒目展示：采用 MapLibre `CircleLayer` + `GeoJsonSource`，绘制蓝色圆点和半透明外圈。理由：不新增 bitmap 资源，不依赖默认 marker 图片，且能确保图层在轨迹线之上。
2. 图例选择：保留现有底部图例样式，新增点击行为。默认 `ALL_SEGMENTS_SELECTED` 表示全选；点击某一段后仅该段地图线条 `lineOpacity=0.9`，其他段 `lineOpacity=0.22`；图例文本颜色也同步降 alpha。再次点击同一图例恢复全选。
3. 顶部按钮：保留刷新、定位到最新点、适应轨迹边界三项功能；为了避免四个控件在窄屏挤压，顶部工具栏改为横向可滚动。
4. “缓存视野”开关：新增 `track_map_cache_visible_tiles` 偏好。打开后：
   - 默认 OpenStreetMap 公共瓦片样式不创建离线 region，只依赖 MapLibre ambient cache 保存用户实际浏览过的瓦片，避免触发公共 OSM 批量离线下载限制。
   - 非公共 OSM 样式 URL 下，在地图 idle 时按当前可见 BBox 和当前缩放创建 MapLibre `OfflineRegion`。
5. 旅行模式设置：移除「管理离线地图区域」入口和「离线地图缓存上限」配置；新增「已缓存地图文件大小」与「清除全部地图缓存」。保留「地图样式 URL」，因为现有 MapLibre 下载能力仍依赖该样式来源。
6. 清空确认：`清空本地轨迹缓存` 与 `清除全部地图缓存` 都改为先弹二次确认，再执行删除。

## 实施内容

- `TrackMapViewFragment.java`
  - 新增当前位置图层：`track_current_location_source`、`track_current_location_halo_layer`、`track_current_location_dot_layer`。
  - 新增图例选择状态 `selectedSegmentIndex`，并用 `RenderedSegment` 记录 segmentIndex、layerId、颜色和 chip。
  - 新增 `cacheVisibleRegionIfEnabled()`：在地图 idle 后按开关状态保存当前视野；对公共 OSM 只提示 ambient cache 行为，对其他样式创建离线 region。
  - 当前位置图层每次刷新都重新放到最上层，避免被轨迹线覆盖。
- `fragment_track_map_view.xml`
  - 顶部工具栏改成 `HorizontalScrollView`，新增 `SwitchCompat`：`track_map_switch_cache_visible_tiles`。
- `TrackerPreferenceNames.java` / `TrackerPreferenceHelper.java`
  - 新增 `TRACK_MAP_CACHE_VISIBLE_TILES` 及读写方法。
  - 删除离线地图缓存上限 key/helper/default。
- `TrackerSettingsFragment.java` / `pref_tracker.xml`
  - 删除 `tracker_open_offline_map_manager` 和 `offline_map_max_mb` 设置项。
  - 新增 `tracker_offline_map_cache_size`、`tracker_clear_offline_map_cache`。
  - 新增本地轨迹缓存和地图缓存清理的 `AlertDialog` 二次确认。
  - 地图缓存大小通过 `MapLibreOfflineMapStore.totalBytes()` 异步计算并写入 summary。
- `MapLibreOfflineMapStore.java`
  - `deleteAll()` 改为删除所有 MapLibre offline regions 后再清理 ambient cache。
  - 新增 `totalBytes()`，按 app 私有目录中 `maplibre/mapbox/mbgl` 命名特征统计地图缓存文件大小。
  - 新增 `enableAmbientCacheRetention()`，通过反射调用 MapLibre `setMaximumAmbientCacheSize`，失败只记日志，不影响地图视图。
- `strings.xml` / `values-zh-rCN/strings.xml`
  - 补齐新增开关、状态提示、确认弹窗、缓存大小和清理文案。
