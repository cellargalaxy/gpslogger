# 260607-204119 执行记录

## 任务结论

本轮修复围绕三个问题：

1. 「轨迹地图」底图不加载 / 只有绿色底图：已把默认地图样式从 MapLibre demo tiles 改为内置 OpenStreetMap 标准 raster 瓦片样式，使用 `https://tile.openstreetmap.org/{z}/{x}/{y}.png`；同时为 MapLibre 网络请求设置可识别的 User-Agent。
2. 「管理离线地图区域」下载范围不直观：已把按钮文案从「下载当前视野」改为「下载当前位置周边 5km」，并在管理页显示计划下载的 BBox 与缩放级别，明确说明缩放 8-15 会被保存，继续放大超过 15 只会复用最高缩放瓦片，不会自动下载更高分辨率。
3. 是否可以改为 OpenStreetMap：结论是「在线底图可行，公共 OSM 瓦片离线预下载不可行」。因此默认在线底图切到 OSM，但离线区域下载在使用公共 OSM 样式时会被 UI 和 `MapLibreOfflineMapStore` 双重拦截；如需离线下载，需要配置自托管或明确允许 offline/prefetch 的 provider style URL。

## 依据来源

- 当前 `TrackMapViewFragment` 原实现从 `TrackerPreferenceHelper.getOfflineMapStyleUrl()` 读取样式 URL，并默认使用 `https://demotiles.maplibre.org/style.json`：`gpslogger/src/main/java/com/mendhak/gpslogger/tracker/ui/TrackMapViewFragment.java`、`TrackerPreferenceNames.DEFAULT_OFFLINE_MAP_STYLE_URL`。
- 当前「离线地图区域」原实现按钮文案是 `tracker_offline_map_download_current_view = Download current view / 下载当前视野`，但代码实际使用 `Session.getCurrentLocationInfo()` 或 last known location，并按固定 `DEFAULT_RADIUS_DEG = 0.05`、缩放 `8, 15` 创建区域：`gpslogger/src/main/java/com/mendhak/gpslogger/tracker/ui/OfflineMapManagerActivity.java`。
- MapLibre Style Spec 支持 raster source、`tiles`、`tileSize`、`minzoom/maxzoom`、`attribution` 等字段：https://maplibre.org/maplibre-style-spec/sources/
- MapLibre Native Android `OfflineTilePyramidRegionDefinition` 以 style URL、bounds、minZoom、maxZoom、pixelRatio 定义离线区域：https://maplibre.org/maplibre-native/android/api/-map-libre%20-native%20-android/org.maplibre.android.offline/-offline-tile-pyramid-region-definition/index.html
- OpenStreetMap Foundation 官方 Tile Usage Policy 要求使用 `https://tile.openstreetmap.org/{z}/{x}/{y}.png`、提供可识别 User-Agent、遵守缓存头；同时明确禁止 bulk download / prefetch / offline use，离线地图应使用自托管瓦片或明确允许离线的 provider：https://operations.osmfoundation.org/policies/tiles/
- MapLibre 11.5.2 sources jar 中存在 `org/maplibre/android/module/http/HttpRequestUtil.java`，源码签名为 `public static void setOkHttpClient(@Nullable OkHttpClient client)`，与本轮代码调用方式一致。

## 方案取舍

- 保留 MapLibre 作为 SDK，不切换到 osmdroid。原因：当前代码已经接入 MapLibre Native Android 11.5.2，并已有 `OfflineManager / OfflineRegion` 抽象；本轮只需修正默认 style 与 UI 行为。
- 默认底图改为内置 OSM raster style，而不是继续依赖远程 demo style。原因：demo style 不是面向用户的真实 OSM 标准底图，用户看到大片绿色时无法判断是否加载成功。
- 不把公共 OSM 瓦片用于离线区域下载。原因：官方政策明确禁止这类预取/离线功能。代码现在允许在线浏览，但阻止离线预下载，避免实现违反服务政策。
- 离线下载 UI 改为如实描述「当前位置周边 5km」，而不是继续称为「当前视野」。当前管理页没有 MapView，也无法知道用户地图视野；如需真正按视野或手动框选，需要后续在管理页加入地图选择器。

## 已实施改动

### 默认 OSM 在线底图

- 新增 `gpslogger/src/main/java/com/mendhak/gpslogger/tracker/offline/OpenStreetMapStyle.java`：
  - 提供内置 MapLibre raster style JSON，source 为 `https://tile.openstreetmap.org/{z}/{x}/{y}.png`。
  - 设置 `User-Agent: GPSLogger-Travel/<version> (<package>; https://github.com/mendhak/gpslogger)`。
  - 识别 `builtin:openstreetmap`、旧 `https://demotiles.maplibre.org/style.json` 和公共 OSM tile URL。
- 修改 `TrackerPreferenceNames.DEFAULT_OFFLINE_MAP_STYLE_URL` 为 `builtin:openstreetmap`。
- 修改 `TrackerPreferenceHelper.getOfflineMapStyleUrl()`：空值或旧 demo 默认值都会回退到 `builtin:openstreetmap`。
- 修改 `TrackMapViewFragment.loadConfiguredStyle()`：内置 OSM 使用 `Style.Builder().fromJson(...)`，用户自定义 style URL 仍使用 `fromUri(...)`。

### 离线下载政策拦截

- 修改 `MapLibreOfflineMapStore.createRegion()`：如果当前样式使用公共 OSM 瓦片，直接抛出异常，避免绕过 UI 发起离线下载。
- 修改 `OfflineMapManagerActivity.onDownloadCurrentArea()`：公共 OSM 样式下点击下载会显示本地化 Toast，并保持下载按钮禁用。

### 离线地图管理页可读性

- 修改 `activity_offline_map_manager.xml`：新增政策提示和下载计划两个 TextView。
- 修改 `OfflineMapManagerActivity`：
  - 默认区域改为以当前位置为中心、约 5km 半径，并按纬度修正经度跨度。
  - 管理页显示计划 BBox、缩放 8-15、超过 max zoom 后不会下载更高分辨率。
  - `setControlsEnabled()` 会根据当前样式是否为公共 OSM 瓦片控制下载按钮状态。
- 修改中英文资源：
  - `tracker_offline_map_download_current_view` 改为 `Download 5 km radius / 下载当前位置周边 5km`。
  - `tracker_offline_map_style_url_summary` 说明 `builtin:openstreetmap` 只用于在线底图，离线下载需要 provider/self-hosted style URL。
  - 新增公共 OSM 下载限制、provider 提示、计划范围等文案。
- 修改 `pref_tracker.xml`：`offline_map_style_url` 默认值改为 `builtin:openstreetmap`。

## 副作用与兼容性

- 已保存旧默认 `https://demotiles.maplibre.org/style.json` 的用户会被 helper 逻辑视为旧默认，并自动回退到内置 OSM；用户主动填写的其他 style URL 不会被改写。
- 使用 `builtin:openstreetmap` 时，轨迹地图在线显示 OSM 标准 raster 底图；离线区域下载按钮不可用。这是政策约束，不是功能缺失。
- 已下载的旧 MapLibre 离线区域仍可在列表中查看和删除；本轮没有迁移或删除既有离线区域。
- 真实「下载当前视野」尚未实现，因为当前离线管理页没有地图视图。后续如要实现，需要在管理页嵌入 MapView 或从轨迹地图页传入当前 camera bounds。
