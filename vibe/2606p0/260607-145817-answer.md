## 方案取舍

- 新增 `scripts/merge-official-master.sh`，默认维护 `upstream=https://github.com/mendhak/gpslogger.git`，并拉取 `upstream/master`。
- 默认采用 `git merge --no-edit upstream/master` 合入官方更新。原因：merge 不改写当前 fork 分支上的定制提交历史，后续继续从官方同步时风险更低。
- 支持 `--mode rebase`，但只作为显式选项提供，因为 rebase 会改写本地提交历史。
- 默认通过 `git status --porcelain --untracked-files=normal` 要求工作区干净，覆盖 staged、unstaged 和 untracked 文件，避免未提交的定制改动和官方更新混在同一次 merge 里；必要时可显式加 `--allow-dirty`。
- 默认不自动 push，避免合并冲突或测试未跑完时直接推送到 fork；需要时可加 `--push`。
- 支持 `--run-tests` 在合入后执行 `./gradlew test`，但默认不跑，避免 Android SDK/Gradle 环境不完整时阻塞同步动作。
