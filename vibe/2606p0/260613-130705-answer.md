# 去除 Custom URL 待发送队列实施记录

生成时间：2026-06-13

## 结论摘要

- 已去除旅游徒步改造中新增的「Custom URL 待发送队列 / Outbox」功能与代码：不再有 Outbox 设置项、队列管理 Activity、Outbox SQLite DAO/Repository/Worker、Outbox 布局资源和 Manifest 注册。
- 已保留 GPSLogger 既有 Custom URL 发送能力：实时 Custom URL 仍由 `CustomUrlManager.sendByHttp()` 序列化 `CustomUrlRequest`，通过 `Systems.startWorkManagerRequest(CustomUrlWorker.class, ...)` 进入原有 WorkManager 路径；CSV 自动发送到 Custom URL 的 FileSender 路径未改。
- 已保留本地轨迹缓存、轨迹地图、离线地图相关能力；本轮只删除与 Custom URL Outbox 队列直接相关的功能。

## 依据来源

- 任务要求来自 `vibe/2606p0/260613-130705-prompt.md`：具体任务为「去除 custom URL 待发送队列 的相关功能与代码」。
- 历史设计文档 `vibe/2606p0/260607-151406-answer.md` 把 Custom URL 队列管理视图列为可选增强，并指出若要管理待补推队列需要新增 `CustomUrlOutbox` 表。
- 当前代码交叉核对确认 Outbox 已落地：修改前存在 `customurl_outbox_*` 偏好、`OutboxQueueActivity`、`OutboxRepository`、`CustomUrlOutboxWorker`、`OutboxDao`、`OutboxEntry`，且 `CustomUrlManager.sendByHttp()` 默认分支会调用 `OutboxRepository.enqueue(...)`。
- 当前实现后的 Custom URL 发送路径已恢复为原 WorkManager Data 方式：`gpslogger/src/main/java/com/mendhak/gpslogger/senders/customurl/CustomUrlManager.java:155`-`:166`。
- 当前 tracker 数据库新建 schema 仅创建本地轨迹表 `local_track_points`：`gpslogger/src/main/java/com/mendhak/gpslogger/tracker/db/TrackerDbHelper.java:23`、`:45`-`:66`。
- 当前设置摘要与设置页只保留本地轨迹缓存、轨迹地图、离线地图：`gpslogger/src/main/res/values/strings.xml:510`、`gpslogger/src/main/res/values-zh-rCN/strings.xml:401`、`gpslogger/src/main/res/xml/pref_tracker.xml:35`、`:61`。

## 方案取舍

- 采用最小删除方案：只删除新增 Outbox 队列能力，不删除官方原有 `CustomUrlWorker`、`CustomUrlRequest`、CSV 批量 Custom URL Sender 和 Custom URL 配置页，避免改变既有用户配置和上游行为。
- `CustomUrlManager.sendByHttp()` 不再读取 `customurl_outbox_enabled`，也不再写入 Outbox；请求直接序列化为 `urlRequests`，交给 `CustomUrlWorker`。
- `TrackerDbHelper` 不再为新安装创建 `customurl_outbox` 表。已有旧安装中如果已经创建过该私有表，本轮代码不再引用它。
- 未新增替代队列管理入口；设置页摘要同步移除 Custom URL 队列字样，避免 UI 暴露已删除能力。

- 删除资源：`gpslogger/src/main/res/layout/activity_outbox_queue.xml`。
- 移除 Manifest 中 `.tracker.ui.OutboxQueueActivity` 注册。
- 移除 `pref_tracker.xml` 中 Custom URL Outbox 设置分类及 `customurl_outbox_*` 配置项。

## 副作用与兼容性

- 断网补推语义回到 GPSLogger 原有 WorkManager 行为；不再提供本地 SQLite Outbox 的独立重试次数、失败留存、队列查看、手动重试和清空入口。
- 本地轨迹缓存和离线地图仍使用 `gpslogger_tracker.db`，但新建库只包含本地轨迹点表。
- 旧版本若已在设备上写入 Outbox 数据，本轮删除主动消费和管理代码后不会再读取这些数据。
- 本轮不改变 Custom URL 模板占位符、HTTP 方法、Header、Body、Basic Auth、CSV 自动发送等既有配置。
